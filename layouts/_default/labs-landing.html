// WHY THESE LABS

Reading About Security
Isn't the Same as Doing It.

Most training stops at slides or needs a cloud account, a vulnerable VM, and an afternoon of setup. CyberSHIELD Labs fit in a lunch break: clone the repo, run one command, and see a real check find a real misconfiguration.

01
NO SETUP TAX

Standard-library Python only. No pip install, no Docker, no API keys, no cloud bill. If you have Python 3.9 or later, you can start now.

02
SAFE BY DESIGN

Every lab uses bundled synthetic data. Nothing touches production systems, and the one network lab refuses to talk to anything except your own machine.

03
HONEST ABOUT LIMITS

Each lab spells out what its checks cannot see. Learning where a control stops is as important as learning what it catches.

// HOW EVERY LAB WORKS

Run It. Break It.
Understand It.

Each lab follows the same three-step loop, so the habit carries over to real reviews.

01
RUN THE CHECK

One command against the bundled synthetic fixture. Read every finding and ask why it fired.

02
EDIT A COPY

Fix the risky settings in a copy of the fixture, or add new ones, and rerun. Watch findings appear and disappear.

03
FIND THE GAPS

Every guide lists what the check misses. Try to sneak a risky input past it, then decide how a real control would catch it.
